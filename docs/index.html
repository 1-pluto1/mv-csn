全部 Stage 3 实验结果总览（11 份结果 JSON 全量同步）

主赛道与消融为 seeds: 42, 1024, 2025 均值±标准差；LLM 级联与错误分析为 Seed-42 单次对照
核心对比结论（含诚实基线对照）： ① 相比未加蒸馏的 MV-CSN v2 (Clean)（Raw F1 仅 0.9200），MV-CSN v3 (2.35M) 将未清洗 Raw F1 拉升至 0.9916（+7.16%），去标点 -P 达全场最高 0.9862，并显著优于固定图 LZASD（McNemar p = 4.11e-11）；② 22K 双师无标注 KD 使跨库零样本 Olivi-9 从 0.6960（Clean-KD Only）跃升至 0.7600（+6.40%）；③ 在同 22K 数据与增强赛道上，RBT3 (Same Data+Aug) 与 RBT3 + MV-CSN v3 总体均值在 1 个标准差内持平（0.9937 vs. 0.9932），但均显著超越 RBT3 (Clean)（p = 0.0107），验证了 22K 双师共识迁移池本身对中轻量编码器均有显著增益，而 MV-CSN v3 则以 1/16.5 的参数量（2.35M vs. 38.8M） 守住了极窄部署成本与抗重度替代韧性。
Qwen3 大模型实测与不确定性级联前沿： 零样本 Qwen3-4B 与 Qwen3-8B 虽然因不依赖关键词捷径而在合成礼貌反事实 CF16/CF40 上拿 1.000，但在真实对抗扰动 Sym40 下将几乎所有混淆正常短信误判为垃圾（Ham Acc 崩至 0.09% / 0.19%）；即使经 15 分钟 Clean-LoRA 微调，Qwen3-4B Clean-LoRA 在 Sym40 上的 Ham Acc 仍跌至 68.88%（F1 = 0.9278），单条 GPU 延迟达 98.0 ms。相反，以 MV-CSN v3 作前置守门员的 Uncertainty Cascade（τ=0.45） 仅上送 1.31%（Bench B v2）/ 2.39%（Sym40）样本，即以 0.200 ms 批有效延迟取得 0.9951 F1，并把 Olivi-9 从 0.7658 拉升至 0.8353。

12 行消融关键发现（含诚实权衡）： ① 移除 Unlabeled Transfer KD 导致跨数据集 Olivi-9 暴跌 −0.0641，是跨库泛化的最大支柱；② 移除 Cross-View & Space Aug 导致未清洗 Raw F1 暴跌 −0.0124，直接证实其在对抗空格/插噪攻击上的决定性作用；③ 移除 Multimodal Anchor、Domain KD 与 Context Gate 均一致损伤多维鲁棒性；④ 两项诚实观察：(a) 移除 Split/Noise Preprocessor 虽使 Fair F1 下降 −0.0016，却使零样本 Olivi-9 反升 +0.0312（规则清洗清除了域内拆字噪音，但也过滤了外域部分原始格式线索）；(b) w/o Dynamic OOV Bridge 在宏观 F1 均值仅差 −0.0002，只因测试集真实 OOV 仅占 2.78%，而 Exp 5 门控剖析证实模型在这些真 OOV 上以 88.54% 权重依赖图桥接。
Benchmark B v2 测试集 (N=3,216) · 3 随机种子均值
高强度对抗与域外泛化对照： 在 60% 字符被篡改的最严苛 sub_only=0.6 压力下，RBT3 (Clean) 跌至 0.9660（-3.00%）、同蒸馏无图 Plain CNN+Trans 跌至 0.9678，而 MV-CSN v3 保持 0.9848（Clean-KD Only 达 0.9871），领先 RBT3 (Clean) +1.88% 与 Plain +1.70%。在外部 12,011 条 Olivi-9 语料上，零样本跨库由 Clean-KD 的 0.6960 通过 22K 双师蒸馏拉升至 0.7600，若放开同源 70/10/20 域内微调则直接达到 0.9336（AUC 0.9794），证明架构表达力充足，剩余差距主源于源/目标域先验漂移。
Seed-42 MV-CSN v3 · 3,216 条测试样本：19 FP (1.78% Ham) + 15 FN (0.70% Spam)
诚实局限与错判洞察： ① 19 条 FP 全部发生在未经攻击的 CLEAN 正常短信（如中奖领票回复、高校/客服通知、房产与促销文案）；② 15 条 FN 集中于 PHON(6)、纯无链接黑话 CLEAN(4)（含生态防火、大棚保温等疑似上游边界样本）及竖排/短域名；③ 在专门构造的 CF16 礼貌短通知反事实探针上，2.35M 单模型 MV-CSN v3 仍对 5/16 条快递柜/医院预约/邮箱回复/初试通知产生高置信误判（CF16 = 68.75% Seed-42，3-seed 0.6250），而联合模型 RBT3 + MV-CSN v3 正确识别其中 3 条（3-seed 0.8125），是明确可继续通过服务类负例难挖掘改进的方向。
