全部实验结果总览（7 组多随机种子验证数据）

所有数值直接由 results/*.json 渲染生成（seeds: 42, 1024, 2025）
核心结论：仅在干净文本上训练、直接零样本测试 3,395 条真实变体短信时，RBT3 F1 跌至 0.9568（漏报率超 8%），LZASD 的 GLYPH/SPLIT 跌至 0.7657 / 0.5625；而独立 MV-CSN v2 (1.37M) 跃升至 F1 = 0.9951（领先 RBT3 +3.83%，McNemar p < 1e-42），RBT3 + MV-CSN v2 达到峰值 0.9964（GLYPH = 0.9827）。
到底需不需要调大模型？不需要。 零样本 Qwen3-4B-Instruct 在正常短信上误杀率高达 59.5%（HamAcc = 0.4050, F1 = 0.8671, 30.74 ms），4-Shot ICL 也仅 0.9421（60.98 ms）；即使做 3-seed LoRA 微调，Qwen3-0.6B 也仅仅与 1.37M 的 MV-CSN v2 打平（0.9951 vs. 0.9951, McNemar p = 0.3833），却付出 438× 参数 和 36.5× 延迟。若确需大模型复核，仅送 0.71%（24/3,395）疑难样本进入 Cascade 级联 即可保持 0.598 ms/条 平均延迟。
消融解读： 去掉 Split/Noise 预处理器 损失最大（−0.0253 F1，方差放大 12 倍）；去掉 RoCBert 图一致性正则 下降 −0.0026（关键的 Clean → Variant 泛化桥）；去掉 Context Gate 或 动态 OOV 桥 分别下降 −0.0008 / −0.0007。单去 Phonetic 或 Glyph 视图整体 F1 变动处于 3 种子方差内（+0.0003~0.0004），因 MIXED 攻击中双视图互为冗余；Exp 5 则证实模型在混淆字上真实同时依赖双视图提供归因与防御冗余。
数据集长度捷径发现： 原始课程 Benchmark A 的 Ham 是长达 191 字的 BBS 论坛长帖，而 Spam 仅 53 字，导致 TFIDF-SVM 只需数长度就能拿到 0.9991；我们按 Spam 长度直方图重新配对采样出 Benchmark B（SMS-Matched 16.5K，p50 = 51 vs. 53，12,992 簇零泄漏划分），彻底封死了长度捷径。
Seed-42 Clean-Trained MV-CSN v2 · 3,395 测试样本总错误率 0.59%
错判审计核心发现： 8 条 FP 全部集中于带银行卡/手机号/期货行情的特殊正常短信（零日常闲聊误杀）；12 条 FN 中有 4 条本身属于上游语料标错样本（气象台大风预警、防疫戴口罩倡议、炒粉点单、水务招标），扣除后真实垃圾短信召回率高达 99.65%。此外，全测试集仅 0.74%（25/3,395）样本落入 (0.05, 0.95) 不确定带，却直接捕获了 35.0%（7/20） 的错判（47× 富集度）。
